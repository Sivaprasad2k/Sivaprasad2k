## ENGINEERING PRINCIPLES

```text
PROBLEM
   ↓
DOMAIN
   ↓
DATA
   ↓
WORKFLOW
   ↓
ARCHITECTURE
   ↓
IMPLEMENTATION
   ↓
DEPLOYMENT
   ↓
OBSERVATION
   ↓
ITERATION
```

- Understand the problem before selecting the technology.
- Model the domain before turning everything into CRUD.
- Treat data modeling as a core part of backend engineering.
- Keep architecture as simple as the problem allows.
- Design APIs around business capabilities, not database tables.
- Build with deployment and failure in mind.
- Use AI where it provides actual application value.
- Prefer understanding over blindly following patterns.
